# taproot.ge Website Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a static, single-page, dark-and-warm informational website for the Tbilisi Bitcoin community (taproot.ge) that invites people to meetups, with coffee & cookies shown as hospitality (no commerce), deployed to GitHub Pages.

**Architecture:** Vite + React + TypeScript SPA. Content lives in typed data files (`events.ts`, `menu.ts`). One small, unit-tested logic module (`lib/events.ts`) partitions/sorts meetups. Section components compose into a single scrolling page with anchored nav. Styling via Tailwind CSS v4 + shadcn/ui, with a single dark "warm espresso" theme where Bitcoin orange is a restrained accent. Deployed to GitHub Pages via a commented Actions workflow using a relative Vite base so it works at the project URL now and the custom domain later.

**Tech Stack:** Vite 6, React 19, TypeScript, Tailwind CSS v4 (`@tailwindcss/vite`), shadcn/ui, Vitest, GitHub Actions (Pages).

- [ ] **Step 5: Implement `src/lib/events.ts`**

```ts
import type { Event } from "@/data/events";

// Parse an ISO date string (YYYY-MM-DD) into a UTC Date at midnight.
const toDate = (iso: string) => new Date(`${iso}T00:00:00Z`);

// Split events into upcoming (date >= reference day) and past (date < reference day).
// Upcoming is sorted soonest-first; past is sorted most-recent-first.
export function partitionEvents(events: readonly Event[], now: Date) {
  const day = new Date(Date.UTC(now.getUTCFullYear(), now.getUTCMonth(), now.getUTCDate()));
  const upcoming = events
    .filter((e) => toDate(e.date) >= day)
    .sort((a, b) => toDate(a.date).getTime() - toDate(b.date).getTime());
  const past = events
    .filter((e) => toDate(e.date) < day)
    .sort((a, b) => toDate(b.date).getTime() - toDate(a.date).getTime());
  return { upcoming, past };
}

// "2026-06-20" -> "Sat, Jun 20, 2026"
export function formatEventDate(iso: string) {
  return toDate(iso).toLocaleDateString("en-US", {
    weekday: "short", year: "numeric", month: "short", day: "numeric", timeZone: "UTC",
  });
}
```

## Task 12: GitHub Pages deploy workflow

**Files:**
- Create: `.github/workflows/deploy.yml`

- [ ] **Step 1: Create `.github/workflows/deploy.yml`** (heavily commented per project conventions)

```yaml
# Builds the Vite site and publishes it to GitHub Pages.
# Trigger: every push to main (plus manual runs from the Actions tab).
name: Deploy to GitHub Pages

on:
  push:
    branches: [main]
  workflow_dispatch: {}   # allow manual runs

# Permissions required by the official Pages deploy action.
permissions:
  contents: read          # checkout the repo
  pages: write            # publish to Pages
  id-token: write         # OIDC token the deploy step needs

# Only one Pages deploy at a time; cancel superseded runs.
concurrency:
  group: pages
  cancel-in-progress: true

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout source
        uses: actions/checkout@v4

      - name: Set up Node
        uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: npm        # cache npm downloads for faster runs

      - name: Install dependencies (clean, reproducible)
        run: npm ci

      - name: Run unit tests
        run: npm test

      - name: Build static site into dist/
        run: npm run build

      - name: Upload dist/ as the Pages artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: dist

  deploy:
    needs: build            # only deploy a successful build
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - name: Deploy artifact to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
```
